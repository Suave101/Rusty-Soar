# Getting Started

This guide takes you from nothing installed to a Soar agent running inside your own Rust
program. Work through the steps in order; each one builds on the last.

| Step | What you will do | Time |
|---|---|---|
| [1. Install](install.md) | Install Rust and build Rusty-Soar | 10 min |
| [2. Run Your First Agent](first-agent.md) | Run an agent from the command line and read its trace | 5 min |
| [3. Put an Agent in Your Program](rust-agent.md) | Create an agent and load rules from Rust | 5 min |
| [4. Inputs and Outputs](inputs-outputs.md) | Send the agent sensor data and read its commands | 10 min |
| [5. Where to Go Next](next-steps.md) | Pick what to learn next | |

## What you need

- A computer running Linux, macOS or Windows.
- A terminal (Command Prompt or PowerShell on Windows).
- Some familiarity with Rust helps for steps 3 and 4, but you can copy the code as it is.

!!! tip "Don't know Soar yet?"

    You can follow this guide without knowing Soar. If a term is unfamiliar, the
    [Glossary](../reference/glossary.md) explains it, and
    [Soar in Ten Minutes](../guides/soar-basics.md) gives the big picture.
